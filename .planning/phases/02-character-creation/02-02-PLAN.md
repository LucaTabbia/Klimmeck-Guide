<objective>
Make the post-creation handover work through the auth source of truth (D-02, D-26): add `adoptUser(User)` to the `AuthTokenService` contract and both implementations, expose it on `AuthCubit`, and make `AuthGate` rebuild when the same user gains a `currentCharacter`.

Purpose: without these two changes a successful "Crea" leaves the user on the creation page forever (Pitfall 1) or lets the service re-emit a stale `currentCharacter: null` later (Pattern 1). This is the CHAR-07 transition mechanism; the screen's `BlocListener` (plan 09) calls `AuthCubit.adoptUser`.
Output: contract + 2 implementations + cubit method + gate rule, each covered by a failing-first test.
</objective>
