## Product rules that bind every plan

- No app-style chrome on gameplay screens (Library, Map, sheets, board): no AppBar, no bottom nav, no loading scaffolding, no spinner; loading only on explicit user action or cold start (rule 2 of CLAUDE.md). The Library refresh after an unlock is silent: no loading state, the page keeps rendering and swaps the data.
- The backend is the source of truth: the FE never decides what is known. It renders `lores` as returned, `known` as received, `loreUnlocked` as received, `City.relatedLore` null as «unknown city»; `unlockedLore` ids are used ONLY to detect a change (refetch) and to compute the «Nuovo» marks against the device baseline (D-01, D-05, D-07).
- Library (D-05..D-07): refetch `lores` only when the set of `unlockedLore` ids changes while a book is shown (compare as sets); sections (types) with no entry are hidden; a book with nothing shows the single status line; «Nuovo» marks = ids not in the baseline saved at the previous opening of the same book for this character; no baseline (first opening) → no marks; the baseline is written when the book is opened (after computing the marks) so the marks disappear at the next opening; live arrivals while open are marked too.
- Portraits (D-08, D-09): `known == false` → full black silhouette of the portrait (same size and placement, `ColorFiltered` or equivalent over the existing picture, ink from the theme), name lines and recommended loot unchanged; the portrait of the strongest enemy follows that enemy's `known`; the result sheet renders what the BE sends (a victory arrives with `known: true`), no client inference from `outcome`.
- Result lines (D-10): one line per `loreUnlocked` entry, label by lore `type` as above, after «Magia appresa», none when empty.
- Map (D-11): a city with `relatedLore == null` opens the paper modal with the city name and the fixed line, without calling `lore(id)`; a city with lore behaves as today; teleport mode unchanged.
- No lore detail page, no hyperlinks, no filtering of the quest narrative paragraphs (out of scope).
