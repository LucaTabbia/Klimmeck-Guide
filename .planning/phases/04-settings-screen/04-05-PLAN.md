## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mutation response → session state | Only `adoptUser` (id-guarded) may change the session user |
| session subtree lifetime | Cubits must not outlive the session/character they were created for |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan | Residual |
|-----------|----------|-----------|----------|-------------|-----------------|----------|
| T-04-05-01 | Spoofing | response for another identity adopted into the session | high | mitigate | hand-over goes through `adoptUser`, which refuses a different `user.id`; refusal → `handoverRejected` (shell test); regression tests for both services | none |
| T-04-05-02 | Information disclosure | late deletion response entering a new session | medium | mitigate | cubits created per shell (keyed by user id and character id) and closed on removal (test); `SafeEmit` swallows late emits | none |
| T-04-05-03 | Information disclosure | preferences cubit bound to the wrong user | medium | mitigate | `userId: user.id` from the AuthGate-built session user; shell recreated per user | none |
| T-04-05-04 | Denial of service | hand-over lost when the Settings page is disposed mid-flight | low | mitigate | listener at shell level (not in the PageView page); `userUpdated` backup (Phase 3) | none |
</threat_model>
