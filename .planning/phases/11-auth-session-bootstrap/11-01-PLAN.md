<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser di sistema → app (deep link `klimmeck://auth`) | URL esterno non fidato che riapre l'app tramite intent/ASWebAuthenticationSession |
| backup Android → storage app | un restore può reintrodurre dati cifrati senza la chiave Keystore |
| repo → binario (`.env` asset) | i valori `.env` finiscono nel bundle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Spoofing | `CallbackActivity` scheme `klimmeck` | mitigate | Lo scheme da solo non autentica: il ticket è inutile senza `code_verifier` (binding S256, implementato in 11-02/11-05); qui solo `exported="true"` richiesto da SDK 31+ e nessun host/path che esponga altro |
| T-11-02 | Information Disclosure | Auto Backup Android | mitigate | `android:allowBackup="false"` su `<application>` |
| T-11-03 | Information Disclosure | `.env.example` | mitigate | Nessun valore reale; nessuna chiave Twitch (D-26); `.env` resta in `.gitignore` |
| T-11-04 | Denial of Service | build release senza `INTERNET` | mitigate | `uses-permission INTERNET` nel manifest main |
| T-11-05 | Tampering | dipendenze pub | accept | Versioni pinnate con caret su package verificati in research (pub.dev, sorgenti letti); lockfile committato |
</threat_model>
