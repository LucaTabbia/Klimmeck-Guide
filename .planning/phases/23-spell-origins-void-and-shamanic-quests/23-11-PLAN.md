Design choices (planner, 2026-11-16; vetoable by the orchestrator before execution):
1. **«Fase di ricerca» replaces «Studiando…»** for every draw quest on the paper, in the quest overlay and above the pawn; «Studiando…» stays for a `study` quest without a draw.
2. **Learning copy:** paper (110 px, one line) «Apprendimento…»; pawn and quest overlay the full line «Imparando «Dardo»: 28 min» (guillemets as in the BE push «Hai scoperto «Dardo»…»).
3. **The paper keeps no countdown**; the countdown lives above the pawn (like «In prigione per: …») and in the overlay.
4. **A school type is a research even without the board quest** (the lane serves `quest { id infos { type } }`); `spellDraw` is read from the board quest (`QuestCubit`), which the BE keeps serving while the lane holds it. Until the gate 23-14 selects `prizes { spellDraw }` a `study` with a draw still reads «Studiando…».
