Rules (research Pattern 5):
1. `toggle`: store `character` as the latest snapshot; intent = `Spellbook.of(character, pending: state.pending).intentFor(spellId)`; `ignored*` → nothing; `blocked*` → emit an outcome (no repository call); `equip`/`unequip` → add `pending[spellId]`, start `Timer(settleTimeout)` with a fresh token, fire the repository call unawaited; return the intent synchronously (the widget uses it for haptics).
2. `sync(character)`: latest snapshot = character; every pending op that matches (equip and id ∈ server active ids; unequip and id ∉ server active ids — server ids = `assets.activeSpells` with non-null spell) is removed and its timer cancelled; ONE emit if anything changed.
3. Repository success (token still current): if the latest snapshot already matches → clear; otherwise remember "succeeded" and wait for `sync` or the timer.
4. Repository failure (token current): remove op, cancel timer, emit `outcome(failed, failure)` in the same emit.
5. Timer expiry (token current): succeeded → silent clear; still in flight → clear + invalidate token + `outcome(failed, timedOut)`; a later answer for that token is ignored.
6. `close()` cancels every timer.

Future<void> _send({required String characterId, required String spellId, required SpellOperation operation, required int token}) async {
  try {
    await (operation == SpellOperation.equip
        ? _repository.equip(characterId: characterId, spellId: spellId)

    if (_tokens[spellId] != token) return;

}
