## Spacing Scale

Declared values (multiples of 4, in Flutter logical pixels):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tight inline padding |
| sm | 8px | Compact spacing between related elements |
| md | 16px | Default element spacing, button internal padding |
| lg | 24px | Section padding, card internal padding |
| xl | 32px | Layout gaps between major blocks |
| 2xl | 48px | Vertical breathing room (logo → tagline gap); bottom offset of animated loading text in SplashScreen |
| 3xl | 64px | Bottom safe area padding on splash |

Exceptions:
- Touch targets for all interactive elements: minimum 44×44 logical px (Flutter `semantics` tap target). Source: docs/rules/ui-ux.md "Target tap ≥ 44x44 logical px".

> Note: SplashScreen existing code uses `50px` bottom padding for `_AnimatedLoadingText`. This must be changed to `48px` to comply with the 4-point grid. This is a minor adjustment with no visual regression risk.

## Typography

All styles are sourced from `KlimmeckGuideTheme.instance` — never inline `TextStyle`. Reference `kg_theme.dart`.

Declared font sizes: **12, 16, 20, 32** (4 sizes max).
Declared font weights: **w400** (regular) and **w600** (semibold).

| Role | Style Ref | Font | Size | Weight | Line Height | Color |
|------|-----------|------|------|--------|-------------|-------|
| Display / Logo | `headlineLarge` | Cinzel Decorative | 32px | w400 | 1.2 | `deepNight` on light; `parchment` on dark backgrounds |
| Title / Section header | `titleMedium` | Cinzel | 20px | w600 | 1.2 | `deepNight` |
| Body narrative | `bodyLarge` | Cormorant Garamond | 16px | w400 | 1.5 | `deepNight` |
| Body UI / labels | `bodyMedium` | Source Sans 3 | 16px | w600 | 1.4 | `deepNight` |
| Special / Flavor / Loading | `specialText` | Uncial Antiqua | 20px | w400 | 1.2 | `parchment` (on dark backgrounds) |
| Error inline | `errorText` | Cinzel | 12px | w600 | 1.3 | `bloodRed` `#9B1C1C` |

> Declared weights: **w400** (regular — Display, Body narrative, Special/Flavor) and **w600** (semibold — Title, Body UI, Error). For the executor: on SignInScreen, tagline uses `bodyLarge`, CTA button label uses `titleMedium`. Error messages use `errorText`.

## Screen Specs

### SplashScreen (immersive — no chrome)

**Layout:** Full-screen `Stack`. No `AppBar`, no `Scaffold` system chrome.

```
┌─────────────────────────────┐
│  splash.png (full bleed)    │
│  BoxFit.fitWidth             │
│                             │
│                             │
│                             │
│  [animated loading text]    │  ← bottom: 48px (token 2xl)
└─────────────────────────────┘
```

**States:**

| State | Visual | Duration |
|-------|--------|----------|
| `SplashBootstrapping` | Full-screen `splash.png` + animated `"Caricamento..."` text cycling 1–3 dots at 500ms intervals (existing `_AnimatedLoadingText`) | Until auth resolves |
| `SplashNetworkDelayed` (after 10s) | Same background + replace loading text with: `"Connessione a Twitch instabile, attendere o accedere manualmente"` + `TextButton` "Accedi manualmente" routing to SignInScreen | Persists until auth resolves or user taps |
| `SplashSessionExpired` | Same background + brief `"La sessione è scaduta, accedi di nuovo."` message shown as `specialText` in `parchment`, then auto-navigate to SignInScreen after 1.5s | Ephemeral, then route |
| `SplashAuthenticated` | No visible change — navigate directly to main shell | Instant |
| `SplashUnauthenticated` (no token) | No animation — navigate immediately to SignInScreen | Instant (D-19) |

**Loading indicator:** Reuse existing `_AnimatedLoadingText` widget with `specialText` style in `parchment` color. Do NOT use `KGLoader` (splash already has its own animation). Do NOT show `CircularProgressIndicator` (not immersive).

**Network-delayed message style:** `specialText` in `parchment`. "Accedi manualmente" button: `TextButton` with `lightText` style.

**No `AppBar`, no `BottomNavigationBar`, no `Scaffold` system chrome.**

### SignInScreen (utility — chrome allowed)

**Layout:** `Scaffold` with `AppBar`. Background: `getBackgroundDecoration()` gradient (`primaryGold` → `darkBronze` → `darkBronze`, top-left to bottom-right).

```
┌─────────────────────────────┐
│  AppBar (darkBronze bg,     │
│  primaryGold fg, no title)  │
├─────────────────────────────┤
│         [lg padding top]    │
│   ┌─────────────────────┐   │
│   │   Klimmeck logo     │   │  ← centered, width 60% screen
│   └─────────────────────┘   │
│         [2xl gap]           │
│   tagline text              │  ← `bodyLarge` Cormorant Garamond, parchment
│         [xl gap]            │
│   ┌─────────────────────┐   │
│   │ Login con Twitch    │   │  ← primary CTA button, see below
│   └─────────────────────┘   │
│         [md gap]            │
│   [error message area]      │  ← `errorText` style, conditionally visible
│                             │
│   footer: TOS · Privacy     │  ← `lightText`, bottom safe area
└─────────────────────────────┘
```

**CTA Button "Login con Twitch":**
- Container: `BoxDecoration` with `LinearGradient(colors: [primaryGold, darkBronze])`, `borderRadius: Radius.circular(KlimmeckGuideTheme.radius)` (15.0)
- Label: `"Login con Twitch"` — `titleMedium` (Cinzel w600 20px) in `deepNight`
- Icon: Twitch logo SVG (white/parchment fill), left of label, 24px
- Minimum tap target: 44px height, full width with horizontal padding md (16px each side)
- State `loading`: Replace label + icon with `SizedBox(width: 20, height: 20)` containing `CircularProgressIndicator(color: deepNight, strokeWidth: 2)`. Button remains visible but non-interactive.
- State `enabled`: gradient as above, fully interactive

**Error display:**
- Inline below the CTA button, not a snackbar
- Style: `errorText` (Cinzel 12px w600 bloodRed)
- Content: `"Errore di connessione, riprova"` (D-22)
- Visibility: shown only when `SignInCubit` emits error state. Hidden (zero-height) otherwise — use `AnimatedSwitcher` or `Visibility` with `maintainSize: false`.

**OAuth cancel (D-21):** No visual feedback. Screen state is preserved unchanged.

**Footer:**
- Two `TextButton`s: "Termini di servizio" and "Privacy" side by side, centered
- Style: `lightText` (EB Garamond 16px w400 parchment)
- URLs: placeholder `#` for v1

**AppBar:** `AppBarTheme` defaults from `materialTheme` (`darkBronze` bg, `primaryGold` fg). No title text. No back arrow (this is root route).

### Logout Confirmation Dialog

**Trigger:** User initiates logout from Settings (Phase 3 scope) or via any future logout path. For Phase 1 the dialog widget must be built and testable, but the trigger screen is out of scope.

**Widget name:** `LogoutConfirmationDialog` — lives in `lib/shared/components/modal/` per existing pattern.

**Surface:** `showDialog` with `barrierDismissible: false`. Material `AlertDialog`.

**Styling:** Use `Theme.of(context)` defaults (Material 3, `colorScheme` defined in `KlimmeckGuideTheme`). Do NOT use game-aesthetic parchment texture here — this is a utility/system dialog.

```
┌─────────────────────────────┐
│  Sei sicuro di voler uscire?│  ← titleMedium (Cinzel 20px w600)
│                             │
│  La tua sessione verrà      │
│  terminata.                 │  ← bodyMedium (Source Sans 3 16px w600)
│                             │
│  [Annulla]    [Esci]        │
│   TextButton   ElevatedBtn  │
└─────────────────────────────┘
```

- Title: `"Sei sicuro di voler uscire?"` — `titleMedium` style
- Body: `"La tua sessione verrà terminata."` — `bodyMedium` style
- Cancel action: `TextButton` label `"Annulla"` — `bodyMedium` in `deepNight`
- Confirm action: `ElevatedButton` label `"Esci"` — `bodyMedium` in `parchment`, background `bloodRed`
- Button order: Cancel left, Confirm right (Material 3 convention)
- `barrierDismissible: false` — explicit choice required (D-11)

## Interaction Contract

| Interaction | Behavior | Source |
|-------------|----------|--------|
| Splash → auth resolved (success) | Navigate directly to main shell. No animation required. | D-17 |
| Splash → no token | Navigate immediately to SignInScreen. No delay, no animation. | D-19 |
| Splash → session expired | Show `"La sessione è scaduta, accedi di nuovo."` for 1.5s then navigate to SignInScreen. | D-10 |
| Splash → network delay after 10s | Show inline message + "Accedi manualmente" button. Retry continues in background. | D-18 |
| "Login con Twitch" tap | Launch `flutter_web_auth_2` system browser. Button enters loading state. | D-15, D-20 |
| OAuth cancel | `PlatformException(CANCELED)` caught silently. SignInScreen restored, no snackbar. | D-21 |
| OAuth error | Inline error shown below CTA. Button re-enabled immediately. | D-22 |
| Token refresh (in-session) | Fully invisible. No spinner, no overlay, no banner. | D-04, REQUIREMENTS SYNC-03 |
| Logout dialog dismiss via "Annulla" | Dialog closes. App state unchanged. | D-11 |
| Logout dialog confirm via "Esci" | Teardown sequence executes (D-12). Navigate to SignInScreen on completion. | D-12 |
| Session revoked in-session | `"La sessione è scaduta, accedi di nuovo."` shown as dialog or snackbar on SignInScreen on arrival. | D-09, D-10 |
